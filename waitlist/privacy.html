Privacy

Last updated 11 November 2026

This site doesn't collect anything about you. There are no forms, accounts, cookies, analytics or trackers.

This website

The page is static: it doesn't ask for your name or email, set cookies, or run analytics or advertising scripts. The demo runs entirely in your browser, and nothing you type into it is sent anywhere.

Other services this page talks to

  • randomuser.me serves the profile pictures in the demo, so it sees the usual request details from your browser, such as your IP address.
  • GitHub hosts the code. When you follow an install link you're on GitHub, and GitHub's privacy statement applies there.

Everything else on this page, including the fonts, is served from this site.

The Hythe app

Hythe runs on your computer. Threads are saved in your own git repository. Live editing goes through hythe-relay, a server you run yourself. Agents such as Claude Code or GitHub Copilot connect to their own providers under your accounts, and those providers' privacy terms apply to that use.

Changes

If we start collecting anything, such as a mailing list, we'll update this notice and the date at the top before we do.
