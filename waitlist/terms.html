Hythe is a prototype you build and run yourself. It's free to try, it will change often, and you should keep your work in git.

Using Hythe

You can download the source from GitHub and run it on your own computer. Use of the code is governed by the license published in the repository.

It's a prototype

Hythe is under active development. Features will change, some will break, and there are no prebuilt or signed downloads yet. It's provided as is, without warranties of any kind. Keep your work committed and pushed, as you would with any tool.

The demo on this site

The Hythe window on our home page is a simulation that runs in your browser. The agents, teammates, terminal and git history in it are scripted. No code is run and nothing you type into it leaves your browser.

Agents and other tools
